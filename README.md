# Linear-Logistic-Regression
## Linear Regression
- This model uses four features to predict the house prices.
- On being trained by data, it finds out the the values of weights and bias.
- Cost Function and gradient descent are implemented.
## Logistic Regression
- This model uses four features to predict the survival of people in the Titanic.
- On being trained by data, it finds out the the values of weights and bias.
- Sigmoid function, cross entropy loss function and gradient descent are implemented.
## Libraries used:
- NumPy
- Pandas
